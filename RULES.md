# Правила сбора новостей

Требования владельца сайта (ainewstobeinformed.ru). Применяются при каждом обновлении.

## Главное
- Собирать **самые полезные** новости каждой категории — такие, чтобы читатель действительно разбирался в теме.
- Новости **не должны повторяться** и не должны быть об одном и том же событии (в пределах подкатегории и, по возможности, между соседними подкатегориями).
- **Ничего не придумывать.** Каждая новость — реальная публикация с рабочей ссылкой. Если нужного количества нет — собрать сколько есть.
- **Дата новости = дата публикации в источнике**, а не дата сбора. Если точную дату установить нельзя — новость не добавлять.
- Период и количество новостей владелец указывает в каждом запросе (например: «1–14 ноября, по 10 новостей»). Количество — на каждую конечную (под)категорию за весь период.
- Новости хранятся всегда: каждое обновление **дополняет** архив, старое не удаляется.

## Формат новости
- Заголовок — по-русски, по сути.
- Пересказ — 2–4 предложения по-русски: что произошло, ключевые цифры/участники, почему это важно. Своими словами, без длинных цитат.
- Ссылка на оригинал и название источника.

## Категории и подкатегории
1. **РБК** — только сайт rbc.ru; материалы по подписке (РБК Pro и т. п.) не брать.
   Политика · Экономика · Бизнес · Исследования · Тренды · Город
2. **RG RU** — только сайт rg.ru.
   Власть · Экономика — Бизнес · Экономика — Финансы · Экономика — Макроэкономика · Экономика — Отрасли · Экономика — Товары и цены · В мире · Происшествия
3. **Общие Мира** — без подкатегорий.
4. **Общие РФ** — без подкатегорий.
5. **Новости Москвы** — без подкатегорий (в запросе владельца был список стран; уточнить при необходимости).
6. **Политика стран** — по странам.
7. **Макроэкономика** — по странам.
8. **Ритейл/FMCG и компании** — по странам.
9. **Oral care** — по странам (рынок товаров для ухода за полостью рта: компании, продукты, продажи, регулирование).

Страны: Россия · США · ЕС · Германия · Австрия · Швейцария · Чехия · Словакия · Венгрия.
Для стран допустимы местные источники на местном языке; пересказ — по-русски.
